# alexnygaard.com

Personal portfolio. Fully prerendered and deployed to Cloudflare.

## Stack

- [SvelteKit 3](https://svelte.dev/docs/kit) + Svelte 5 (runes), Vite 8, TypeScript 6
- [Tailwind CSS 4](https://tailwindcss.com) via `@tailwindcss/vite`, theme tokens in `src/app.css`
- [mode-watcher](https://mode-watcher.svecosystem.com) for light and dark mode
- [Libron](https://github.com/nicoverbruggen/libron) by Nico Verbruggen, self-hosted from `static/fonts` (SIL OFL)
- [shadcn-svelte](https://shadcn-svelte.com) is configured (`components.json`) for adding components; only `button` is installed
- `@sveltejs/adapter-cloudflare`, oxlint, Prettier

## Layout

- `src/lib/data/` holds all content: work, education, projects, tech, site links
- `src/lib/components/` holds page building blocks; `ui/` is generated by shadcn-svelte

Imports use Node subpath imports (`#lib/...`, declared in `package.json`), which replace `$lib` in SvelteKit 3.

## Commands

```bash
pnpm install
pnpm dev          # dev server
pnpm check        # type-check
pnpm lint         # oxlint
pnpm format       # prettier
pnpm build        # production build
pnpm preview      # serve the build locally
```

Add a shadcn-svelte component with `pnpm dlx shadcn-svelte@latest add <name>`.
